Privacy Policy

Last updated: November 21, 2026

About the application

Rclone Personal Drive is a personal desktop integration that uses rclone to access Google Drive on Linux.

Google Drive data

The application requests permission to access Google Drive files for personal file management, including browsing, downloading, uploading, editing, and synchronization.

Data storage and sharing

Authentication credentials and temporary file caches are stored locally on the user's computer. This integration does not operate a separate application server or intentionally share Google Drive data with third parties.

Data retention

Local credentials and cached data are retained according to the user's rclone configuration and can be removed by the user.

Revoking access

Google Drive access can be revoked through the Google Account security settings.
